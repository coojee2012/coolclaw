👥 用户管理

ID 用户名 角色 创建时间 操作

两层分类，别混为一谈

CoolClaw 先选专家（干什么活），再按模型 role（哪类模型来干）从池里挑具体模型。

① 专家（Expert）— 任务分工

build / chat / explore / oracle / ocr / vision …

  • 由 OMO 能力路由 + src/experts.py 定义
  • 不在 config.yaml 里列专家表
  • 可在「专家路由」页绑定 Provider 偏好
② 模型 role — 能力标签

coding / general / fast / thinking / ocr / vision / documents

  • 本地模型：写在 config.yaml
  • models.local.<名>.role: coding
  • 云端：按模型名自动推断，或加 roles: 手动指定

config.yaml 里你能看到的 role

models:
  local:
    qwen2_5_3b:
      path: /path/to/model.gguf
      role: fast          # 轻量 / 调度
    qwen2_5_coder_7b:
      path: ...
      role: coding        # 编程专家用
    lightonocr_2_1b:
      path: ...
      role: ocr           # 建议 OCR 模型用 ocr，不要用 general

proxy:
  providers:
    google_ai:
      model: gemini-3.5-flash-lite
      roles:              # 可选，不写则按模型名自动推断
        - general
        - coding
        - fast

「启用此模型」按钮会把本地 GGUF 的 role 写入上述位置。云端 Provider 在「云端 Provider」页配置后写入 proxy.providers。
